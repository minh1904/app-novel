# Tài liệu theo module

Cập nhật: 2026-10-10 · Trạng thái: mục lục tài liệu module của Mira.

Mỗi thư mục là nơi chịu trách nhiệm cho một phạm vi sản phẩm hoặc kỹ thuật. Quyết định, hành vi
và cách vận hành được viết tại module liên quan.

| Module | Mục đích |
| --- | --- |
| [Hệ thiết kế giao diện](design-system/README.md) | Nghiên cứu, quyết định và trạng thái của token/component; quy tắc UI hiện hành ở [`DESIGN.md`](../../DESIGN.md) |
| [Kiến trúc frontend](frontend-architecture/README.md) | Bằng chứng và trạng thái refactor renderer; quy tắc repository ở [`ARCHITECTURE.md`](../../ARCHITECTURE.md) |
| [Kết nối AI](ai-connections/README.md) | Provider, khóa API, chọn model, onboarding và trạng thái kết nối subscription |
| [Ngữ cảnh dịch](context/README.md) | Glossary, nhân vật, xưng hô, văn phong, ký ức và cách lắp ngữ cảnh |
| [Bộ đo chất lượng](measurement/README.md) | Fixture, phép kiểm, chạy thí nghiệm, chấm mù và báo cáo |
| [Đề xuất và phiên AI](proposals/README.md) | Duyệt thay đổi tại editor, lịch sử phiên và hàng chờ theo chương |
| [Nguồn và cập nhật](sources/README.md) | Chương gốc đến từ đâu, phát hiện chương mới và raw bị sửa, trang Cập nhật; nghiên cứu cách làm và rủi ro pháp lý |
| [Phiên làm việc theo tác phẩm](workspace/README.md) | Tab truyện, khôi phục vị trí và bảo vệ bản sửa chưa lưu |

Tài liệu module phải phân biệt hành vi đã chạy, kết quả một thí nghiệm, đề xuất và quyết định sản
phẩm. Với phần chưa làm, tài liệu module tập hợp mục tiêu, bằng chứng và câu hỏi cần chốt; OpenSpec
đặc tả change trước khi triển khai. Khi đã làm xong, tài liệu module mô tả hệ thống và cách dùng.
